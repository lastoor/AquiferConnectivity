## Environment policy

- Do not create or install a new Conda, virtualenv, or other Python environment without the user's explicit consent.
- For local Apple Silicon Step 5 runs, use the existing `taichi` Conda environment through `submit_step5_mac_m4.sh` unless the user explicitly requests a different environment.
